# FreeDiving

## 概要
モリを使用した海に潜るゲーム
ステージを選択した後は海に潜り、自身の持つ槍を使用して、魚を取り、帰ってくる
モリはグレードアップすることができる
最終的にはスキューバダイビングなどもできるようにしていく
→船に乗ってステージ移動などを行うようにする

できるだけ現実の動作と似ているようなゲームにしたいと考えている
以下例
・魚にモリが刺さらなかったりする
・耐久値がある
・ダイビングスーツなどを着用し深くまで潜る場合は地上に上がった際に酸素室のような場所に入らなければいけない

## 検討中

インベントリとかについて考えてること
・重量システム入れるかどうか（ダクソ的な）
・耐久力入れるかどうか
・そもそもインベントリ自体用意した方がいいのか　アイテムのサイズ制度の導入とかも考え中
（現実の素潜りとかでどうしてるかの調査必要そう　なんか銛に魚を重ねて刺して陸に上がってることもあった気がする）
何を持って次のステージに進行することができるのかを決めなければいけない
・お金を使用して解放するのか？
→一定レベルのステージまでは解放されいるがその先はお金を払ってボートや船を買うことで行けるようにする等
