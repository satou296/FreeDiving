# FreeDiving

## 概要
モリを使用した海に潜るゲーム
ステージを選択した後は海に潜り、自身の持つ槍を使用して、魚を取り、帰ってくくる
モリはグレードアップすることができる
最終的にはスキューバダイビングなどもできるようにしていく
